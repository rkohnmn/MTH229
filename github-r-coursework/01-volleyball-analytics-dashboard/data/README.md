# Data Sources & Schema: Volleyball Analytics Dashboard

This directory contains datasets used by the Volleyball Analytics Dashboard and statistical modeling scripts.

---

## 1. Ball Position Tracking Data (`ball_positions_sample.csv`)

- **Origin**: Generated directly via a custom computer vision tracking pipeline (`tracking_pipeline/`) applied to the broadcast footage of the Italy vs. Poland Men's Volleyball Nations League (VNL) 2025 Grand Finals.
- **Processing**: Video frames were extracted at 10–25 fps and processed using YOLOv8 object detection (`yolov8n.pt` / `ovml` 4-mvb model) to extract bounding box coordinates.
- **Coordinate Transformation**:
  - `u`: Normalized horizontal image coordinate $[0, 1]$, mapped to court physical coordinates $x \in [-9, 9]$ meters (18m total court length across both sides of the net).
  - `v`: Normalized vertical image coordinate $[0, 1]$, mapped to court physical coordinates $y \in [0, 9]$ meters (9m court width).
- **Files**:
  - `ball_positions_sample.csv`: Representative sample of 10,000 detection records included directly in the repository for fast reproduction.
  - The full 267,000-record dataset can be regenerated by running the tracking pipeline in `tracking_pipeline/` on the match footage or supplied separately.

## 2. PlusLiga Historical Match Data (`Mens-Volleyball-PlusLiga-2008-2023.csv`)

- **Origin**: Polish Men's Volleyball League (PlusLiga) match statistics from 2008 through 2023.
- **Source**: Kaggle dataset compiled by Kacper Gregorowicz ([Kaggle Link](https://www.kaggle.com/datasets/kacpergregorowicz/-mens-volleyball-plusliga-20082022)).
- **Key Variables**:
  - `Date`: Match timestamp.
  - `Team_1`, `Team_2`: Competing clubs.
  - `T1_Srv_Eff`, `T2_Srv_Eff`: Serve efficiency percentages.
  - `T1_Rec_Perf`, `T2_Rec_Perf`: Perfect reception percentages.
  - `T1_Att_Kill_Perc`, `T2_Att_Kill_Perc`: Attack kill percentages.
  - `T1_Blk_Sum`, `T2_Blk_Sum`: Total block points per team.
  - `Winner`: Binary outcome indicator (`0` = Team 2 won, `1` = Team 1 won).

---

## 3. Beach Volleyball World Tour Data (`vb_matches_sample.csv`)

- **Origin**: International Beach Volleyball tournament match records across AVP and FIVB circuits.
- **Source**: Kaggle dataset compiled by Jesse Mostipak ([Kaggle Link](https://www.kaggle.com/datasets/jessemostipak/beach-volleyball)).
- **Key Variables**:
  - `gender`: Match gender division (`M` for Men, `W` for Women).
  - `duration`: Match length recorded as `HH:MM:SS`.
  - `w_p1_age`, `w_p2_age`: Winning pair player ages.
  - `l_p1_age`, `l_p2_age`: Losing pair player ages.
  - `circuit`, `tournament`, `year`: Competition context.
- **Files**:
  - `vb_matches_sample.csv`: Sample of 3,500 representative match records included directly.
  - The full dataset (30.5 MB) is publicly accessible via the Kaggle link above.
